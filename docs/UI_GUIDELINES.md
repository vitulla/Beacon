# Beacon UI Guidelines

## Philosophy

Beacon should feel calm, fast, intentional, and effortless.

The interface should disappear behind the information.

---

# The Three Layers

Layer 1

Glance

Information should be understood in under three seconds.

---

Layer 2

Explore

Tapping reveals additional information without overwhelming the user.

---

Layer 3

Conversation

Holding the button activates AI.

When finished, Beacon returns to the previous Card.

---

# Visual Hierarchy

Every Card contains:

1. Icon
2. Title
3. Primary Information
4. Secondary Information
5. Interaction Hint (optional)

---

# Typography

Large text

Primary information.

Medium text

Supporting information.

Small text

Status.

Never use more than three text sizes.

---

# Colors

Dark first.

Automatic Day / Night.

One accent color.

Avoid unnecessary colors.

Colors should communicate meaning.

---

# Motion

Motion should communicate change.

Never animate for decoration.

Transitions should be smooth and subtle.

---

# Cards

Cards should respect the circular display.

Avoid rectangular layouts inside circular screens.

Whitespace is encouraged.

---

# Sounds

Sounds should confirm actions.

Never demand attention.

---

# AI

AI is an overlay.

It is never the Home screen.

Conversation should always return to the originating Card.

---

# Navigation

↓

Card Rotation

↓

Tap

↓

Explore

↓

↓

---

# Golden Rule

Every screen should answer one question.

Every interaction should reward curiosity.
