# Beacon

> **Curiosity at a Glance.**

## Mission

Beacon is a modular desktop companion that quietly surfaces relevant information, encourages exploration, and uses contextual AI to answer questions.

It should feel calm, beautiful, informative, and effortless.

Beacon exists to reward curiosity without demanding attention.

---

# Design Principles

## Calm

Beacon never competes for your attention.

## Curious

Every interaction should reward exploration.

## Glanceable

Information should be understood within three seconds.

## Contextual

AI understands what you're looking at.

## Intentional

Every pixel, animation, sound, and interaction should have a purpose.

---

# Core Interaction

```
Glance
   ↓
Explore
   ↓
Ask AI
```

Beacon should never go deeper than this interaction model.

---

# Beacon is NOT

- A chatbot
- A dashboard
- A tablet
- A notification center

Beacon is a desktop companion.
